  Your clients, audits and rankings stay on THIS computer.

  No API keys needed to start.


-----------------------------------------------------------
  STEP 1 - EXTRACT THIS FOLDER FIRST
-----------------------------------------------------------

  If you are reading this INSIDE the ZIP file, stop and
  extract it first. The app cannot run from inside a ZIP.

    1. Close this window.
    2. Right-click the ZIP file you downloaded.
    3. Choose "Extract All..." then "Extract".
    4. Open the new folder that appears.

  Keep every file together in that folder. The launcher
  needs the "_system" folder that sits next to it.


-----------------------------------------------------------
  STEP 2 - OPEN THE LAUNCHER FOR YOUR COMPUTER
-----------------------------------------------------------

  Double-click the one that matches your computer:

    Windows ..... SEO Tool - WINDOWS
    Mac ......... SEO Tool - MAC
    Linux ....... SEO Tool - LINUX

  A small window opens with one button.


-----------------------------------------------------------
  STEP 3 - CLICK SET UP, THEN WAIT
-----------------------------------------------------------

  Click "Set up the SEO Tool". There is nothing to fill in.

  It fetches what the app needs and builds it. Be honest
  with yourself about the wait: this is a full web app, so
  the first run takes about 3 to 10 minutes and downloads
  a few hundred MB. Every run after that starts in seconds.

  A black window appears while it works. Leave it alone -
  it closes on its own.

  You do NOT need administrator rights. Nothing is added to
  Windows outside this folder. If Node.js is not on your
  computer, the setup fetches its own private copy and keeps
  it inside this folder - it does not touch anything you
  already have installed.

  Windows may warn "Windows protected your PC" because this
  app is not code-signed (a certificate costs about $300 a
  year, which would defeat the word "free"). Click
  "More info", then "Run anyway".


-----------------------------------------------------------
  FROM NOW ON
-----------------------------------------------------------

  Open the same launcher any time. It is your Open button,
  your Update button and your Backup button, all in one
  file. It opens a control panel in your browser with:

    Open the app ...... starts it and opens it
    Start / Stop ...... runs it, or shuts it down
    Update ............ pulls the newest version
    Back up now ....... a complete copy of your database
    Restore ........... puts a backup back (it asks first)
    Collect info ...... diagnostics to paste into an issue


-----------------------------------------------------------
  YOUR FIRST 10 MINUTES
-----------------------------------------------------------

  1. Add a client - paste any website address. The tool
     detects the platform and the niche by itself and
     builds a task plan around what it finds.

  2. Run an audit. 40+ checks, sorted by how much they
     matter. This works with nothing else set up.

  3. Connect Google Search Console (free, about 5 minutes).
     This is the big one: it replaces guessed rankings with
     Google's own numbers, and unlocks traffic and quick
     wins. The tool works without it, but it is the single
     thing that most changes what you get out of this.

  4. Optional: add a free AI key (Gemini or Groq) for
     plain-English explanations, written fixes and
     executive summaries.


-----------------------------------------------------------
  WHERE IS MY DATA?
-----------------------------------------------------------

  One file: "_system\data.db", inside this folder. Every
  client, audit, keyword, ranking and report lives in it.
  Copy it anywhere - that is your whole install.

  Back it up from the control panel: "Back up now". It
  writes a complete, consistent snapshot next to the
  database. "Restore this backup" puts one back, and copies
  your current data aside first so a wrong choice is
  undoable.


-----------------------------------------------------------
  IF SOMETHING GOES WRONG
-----------------------------------------------------------

  Open the launcher and choose "More options" ->
  "Get help on GitHub", or use "Collect info for support"
  in the control panel and paste what it gives you into a
  new issue:

    https://github.com/IamRamgarhia/All-In-One-Free-SEO-Tool/issues

  Common ones:

  "It says some files are missing"
      The ZIP was only half extracted. Extract it again,
      keeping every file together.

  "Nothing happens when I double-click the launcher"
      Windows sometimes blocks files from the internet.
      Right-click the launcher -> Properties -> tick
      "Unblock" at the bottom -> OK, then try again.

  "The first setup failed"
      Almost always no internet, or antivirus holding a
      file while it is being written. Open the launcher and
      choose "Set up again (repair)".
